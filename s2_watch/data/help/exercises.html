Exercises

S2 Watch recognises exercise and test traffic so a drill never passes for a real event.

Exercise in Progress

Configuration → Exercise in Progress tells S2 Watch an exercise is running.

Off (the default)On
Exercise messagesKept in Live Monitor and History, marked “EXERCISE:”, but not news Judged like real traffic: news lists, events, map, alerts
Marking—A red EXERCISE marker by the clock; “EXERCISE:” in the list; a red line in the event panel; reports and briefings get “EXERCISE:” in the subject and EXERCISE EXERCISE EXERCISE as first and last lines
Real trafficHandled as usual, alongside the exercise
Test trafficNever news

Switching it on re-checks the watch period, so injects already received are picked up. Turn it off after ENDEX: exercise traffic then leaves the news lists and events. Exercise messages never count toward station track records or keyword noise.

What counts as exercise traffic

Radio messages only (JS8Call, MagCommstat, Commstat, FLMSG, JS8SuperSpotter, APRS), and only with clear markers. Capital letters don't matter.

Recognised as exercise traffic:

W1AW: @MAGNET EXERCISE EXERCISE EXERCISE DAM FAILURE AT LAKE X
EXERCISE: TORNADO DAMAGE IN TULSA
THIS IS A DRILL. BRIDGE COLLAPSE ON I-35
EXERCISE MESSAGE 3 OF 5 - FLOODING
FOR EXERCISE PURPOSES ONLY - SHELTER OPEN AT ADA HS
SIMULATED EMERGENCY: CHEMICAL SPILL ON RT 66
STARTEX 1400Z
NOT REAL WORLD - POWER OUT IN OKC

Treated as real traffic:

REAL WORLD: EXERCISE SUSPENDED, ACTUAL TORNADO IN TULSA     (real world wins)
NO DUFF NO DUFF EXERCISE EXERCISE INJURED PERSON AT SITE    (no duff wins)
Report actual events (not exercise or test)                 (no marker)
Exercise caution on I-40 after the storm                    (a lone word)
State Dept: Kenya - Level 1: Exercise Normal Precautions    (official feeds never count)

Test traffic (never news):

THIS IS A TEST OF THE NET
RFI test message
TEST TEST DE W1AW

Tips for exercise planners

  • Start every inject with EXERCISE EXERCISE EXERCISE. A message with no marker looks like real traffic.
  • In FLMSG forms, put the marker in the subject or message text: a field that just says “EXERCISE” isn't enough.
  • An inject must still be kept by a watch form: one with news words (flood, outage, injured…) is kept by the Topics; for injects without them, tick that application's “All … messages” form for the exercise.
