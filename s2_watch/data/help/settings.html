The setup walk-through can be run again at any time: s2-watch --configure (Windows: Start menu → S2 Watch Setup).

Your data

Settings, watch forms, reports, labels, notes, entries and history live in one file, s2_watch.db. Once a day S2 Watch copies it to a backups folder beside it and keeps the last 14 copies. To restore one: quit S2 Watch and copy a backup over s2_watch.db.

Updating

The button beside the clock says Up to date, and turns orange, Update to 0.42.0, when a newer S2 Watch is released on GitHub. S2 Watch checks 10 seconds after it starts and every 6 hours; click Up to date to check now (Updates? means it couldn't reach GitHub; it tries again later).

Click the orange button to install the update. It lists what's new and asks first; then S2 Watch downloads the update, closes, saves a copy of the database in its backups folder (s2_watch-before-0.42.0.db), runs the installer and opens again, about a minute later on Linux and macOS. The status bar then says Updated to S2 Watch 0.42.0, or, if it didn't install, that you are still on the old version and where the details are (update.log beside s2_watch.db). A failed download leaves S2 Watch running as it was.

The button installs updates only for a copy set up by the Linux or macOS installer. Installed with Git, it tells you to run git pull; on Windows it opens the download page.

Installed with Git (recommended): quit S2 Watch, then in the folder you cloned:

git pull

Start S2 Watch again. If an update needs new packages, it installs them as it starts.

Installed from a release package: download the newest release and run its installer the same way. Either way your data is kept.

Full instructions: the install page. The version is shown under Help → About S2 Watch.
