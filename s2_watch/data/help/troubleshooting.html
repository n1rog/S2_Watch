Troubleshooting

What you seeWhy, and what to do
No reports at all; source lights grey “Not monitored”No watch form is ticked. Tick the Topics (or a Whole applications form) under Watch forms.
JS8Call: DisconnectedJS8Call isn't running, or its TCP server API is off (JS8Call: File → Settings → Reporting). Check host and port (127.0.0.1, 2442) under Configuration → Sources…, then Connect to monitored applications.
History can't find a messageOnly messages a watch form kept are saved. Check the call sign's spelling (K9DGY, not K9DGJ), and try fewer words: every word must appear.
A real report wasn't flaggedNo keyword matched. Look under Possible Misses (with Ollama), add a keyword there, or widen a watch form.
Chat flagged as newsMark it Ignored (X). If one word keeps causing it, stop it under Reports → Keyword Noise.
A report is in the wrong placeUse fix location in the event panel (Reliability tools).
Two incidents merged, or one splitGrouping is a best guess; it errs toward keeping reports apart. Tell N1ROG with the event titles.
“failing: gdelt” in the status barGDELT news refused the request (“429 Too Many Requests”). S2 Watch retries in 30 minutes.
No FEMA public alerts (IPAWS)The archive runs a day behind: use a watch period of 2 days or more.
APRS: “server refused the login”APRS-IS needs a real call sign: enter yours with an SSID under Configuration → Sources…
“The map was stopped … reloading it”The computer ran short of memory and the map's engine was stopped; S2 Watch reloads it. If it keeps happening, close memory-hungry programs (browsers with many tabs).
Markers vanish while zoomingConfiguration → Display… → Software map rendering, then restart.
Nothing from abroad, or no more U.S. alertsCheck Configuration → Coverage: worldwide sources keep only covered areas, and U.S. sources pause while the United States is unticked.
Map markers, reports or events disappeared after changing CoveragePlaces in unticked areas hide (nothing is deleted). Tick the area again under Configuration → Coverage to see them.
A message about a U.S. town was placed abroadUse fix location and tick Remember (Reliability tools). Adding the state helps: “Paris, TX”.
An exercise inject shows as realIt had no exercise marker (Exercises).

Still stuck? Note what you did, what you expected and what happened (a screenshot helps), and send it to N1ROG.
