Getting started

S2 Watch reads the radio messaging applications you already run and a set of official and open sources, picks out the reports that matter, groups them into events, checks them against official sources, and drafts MAGNET S2 reports and briefings. It only reads: it never transmits.

The main window

PartWhat it is for
Map tabThe map, and under it the Newsworthiness list. Watch period sets how far back the list and map reach; Map filters chooses layers; Draft briefing… starts a shift briefing.
Newsworthiness: Events | ReportsEvents groups reports about one happening into one line (the default); Reports lists every report on its own. Select an event and the event panel beside the list says what it is about. Search above the list finds events and reports by any words (Searching).
Events tabAll events in a period you choose, with filters, a search and the same event panel.
Possible MissesRadio messages the watch forms didn't keep that the local AI thinks are news (Local AI).
Live Monitor / HistoryEvery kept message as it arrives / a search of everything saved.
MetricsReports by category, region and source over time.
Clock (top right)Local or Zulu time; Show Zulu / Show Local switches every time in the app.

A typical watch

  1. Glance at the map and the Events list: new and updated events are highlighted for a few seconds.
  2. Select an event and read the panel: its reports in full, whether an official source confirms it, how far ahead radio was, and any warnings (single source, radio silence).
  3. Label what matters: Of interest, Follow-up created or Ignored (Labels).
  4. Draft a follow-up report on an event, or a shift briefing at the end of the watch (Reports and briefings).

Example. K6NLX sends a StatRep: NA[NWS PHOENIX: DUST STORM NEAR MARICOPA, AZ]. A minute later the same message arrives through JS8SuperSpotter.

  • The two copies become one report (2 copies), placed at Maricopa, AZ, category Climate / Environment.
  • It becomes the event Dust storm near Maricopa, AZ; an active NWS High Wind Warning there marks it ✓ Confirmed.
  • The panel shows K6NLX's track record (for example B, usually reliable) beside the report.
  • Right-click the event → Draft follow-up report… gives a MAGNET S2 report with the timeline and sources already filled in.

First time? Set your sources, your focus regions, and look at the watch forms. The setup walk-through (s2-watch --configure) asks about all of these.
